## 🧠 Project Overview | 项目概述

This repository explores a **Dual-Brain architecture** for autonomous vehicles —  
the *Left Brain* focuses on **end-to-end perception and trajectory execution**,  
while the *Right Brain* focuses on **safety reasoning, risk prediction, and rule-based inference**.

本项目提出一种面向自动驾驶的“双脑架构”：  
左脑负责**感知与执行**，右脑负责**安全推理与风险预测**，  

Design premises and non-delegable judgment principles are articulated in the Judgment Before Intelligence repository.
